# Frontend (Next.js / TypeScript / Tailwind CSS)

Aplicação web unificada para a plataforma Agnitio:
- **Painel do Fotógrafo**: Área autenticada para criação e gerenciamento de eventos, upload paralelo de fotos em lote com concorrência controlada e acompanhamento de progresso em tempo real via Server-Sent Events (SSE).
- **Galeria Pública**: Visualização pública das fotos dos eventos com renderização no servidor (SSR) para geração de Open Graph / metadados em redes sociais e fluxo de busca por selfie com consentimento prévio de privacidade (LGPD).

Implementação prevista para as **Fases 2 e 3** do roadmap.
